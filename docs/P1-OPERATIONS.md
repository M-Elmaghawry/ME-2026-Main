# تشغيل إعدادات P1

## بيانات التواصل

البريد المعتمد `info@elmekawy-bim.com` والموقع المعتمد «المنصورة، مصر» موجودان في `src/config/site.ts`؛ وتستخدمهما صفحة التواصل والتذييل والبيانات المنظمة للصفحات. لم تُغيّر مواقع المشروعات أو أماكن الدورات السابقة.

## السعر الرسمي والعروض

عدّل `src/data/coursePricing.ts` باستخدام معرّف الدورة. لا تحتاج العروض إلى تعديل مكونات الصفحة.

مثال لإضافة عرض إلى دورة الريفيت الاحترافية:

```ts
'revit-structure-professional-training': {
  officialPrice: 130,
  currency: 'USD',
  offer: {
    price: 99,
    startsAt: '2026-12-01T00:00:00+03:00',
    endsAt: '2026-12-31T23:59:59+03:00',
  },
},
```

- `officialPrice`: السعر الرسمي؛ `null` لطلب السعر بالتواصل، و`0` للدورة المجانية.
- `currency`: رمز العملة مثل `USD` أو `SAR` أو `EGP`.
- `offer.price`: سعر أقل من السعر الرسمي.
- `offer.endsAt`: تاريخ نهاية مطلوب، مع منطقة زمنية صريحة. `+03:00` يعني توقيت الرياض.
- `offer.startsAt`: بداية اختيارية. عند حذفها يبدأ العرض فور نشر الإعداد.
- قبل البداية وبعد النهاية يظهر السعر الرسمي دون خصم أو عدّاد. يعود السعر الرسمي عند لحظة الانتهاء حتى لو بقيت الصفحة مفتوحة.
- حذف `offer` يلغي العرض. بعد تغيير الملف، أعد البناء والنشر.

لا يوجد عرض مفعّل افتراضيًا. استُخدم 130 دولارًا، وهو السعر الأصلي الموجود سابقًا، سعرًا رسميًا للدورة الاحترافية. تبقى أسعار الورش غير المحددة متاحة بالتواصل. الحسابات المعروضة تعتمد على ساعة متصفح الزائر؛ التسجيل والتسعير النهائي يتمان عبر التواصل، ولا توجد عملية دفع داخل الموقع.

## نموذج التواصل وEmailJS

أضف القيم الحقيقية في `.env` محليًا، وفي GitHub Actions Secrets عند النشر:

```text
VITE_EMAILJS_SERVICE_ID
VITE_EMAILJS_TEMPLATE_ID
VITE_EMAILJS_PUBLIC_KEY
```

المتغيرات `VITE_*` عامة داخل نسخة المتصفح. لا تضع فيها كلمات مرور أو مفاتيح خاصة. متغيرات القالب المرسلة هي `from_name` و`from_email` و`phone` و`company` و`service` و`message`؛ اجعل مستلم البريد ثابتًا في قالب EmailJS، واستخدم `from_email` للرد على المرسل.

النموذج يتحقق من المدخلات ويمنع الإرسال المتزامن، ويحد المحاولات إلى محاولة كل دقيقة، ويستخدم حقلًا مخفيًا لمكافحة الرسائل الآلية. يحفظ المدخلات عند فشل الإرسال، ويعرض بديل واتساب إذا غابت الإعدادات. هذه ضوابط في المتصفح ويمكن تجاوزها؛ قيود الخدمة هي الحماية المكملة.

في حساب EmailJS، راجع قائمة النطاقات المسموح بها وأضف نطاق الإنتاج ومصدر GitHub Pages المستخدم. توثيق الخدمة يشرح [قيود النطاق ومكافحة الإساءة](https://www.emailjs.com/docs/faq/does-emailjs-expose-my-account-to-spam/) و[خيارات SDK وتحديد المعدل](https://www.emailjs.com/docs/sdk/options/).

### تفعيل reCAPTCHA اختياريًا

1. أنشئ مفتاح **reCAPTCHA v2 Checkbox** للنطاقات المستخدمة.
2. أضف المفتاح العام إلى `VITE_RECAPTCHA_SITE_KEY` في `.env` محليًا، وإلى متغير GitHub Actions بنفس الاسم عند النشر.
3. فعّل **Enable reCAPTCHA V2 verification** في إعدادات قالب EmailJS، وضع المفتاح السري هناك فقط.
4. أعد البناء والنشر واختبر الإرسال على النطاق المسموح.

تدعم الشيفرة عرض التحقق وتمرير الرمز إلى EmailJS ومسحه بعد المحاولة أو عند انتهاء صلاحيته. عند تفعيل المفتاح لا يسمح النموذج بالإرسال دون رمز. لضمان فرض التحقق من جهة الخدمة، يجب إتمام خطوة إعداد القالب؛ راجع [تعليمات EmailJS الرسمية](https://www.emailjs.com/docs/user-guide/adding-captcha-verification/).

لم يُرسل بريد فعلي ولم تُعدّل إعدادات حساب EmailJS خلال تنفيذ هذه المرحلة.

## اللغة وبيانات الصفحات

الأولوية للغة الصريحة في الرابط (`?lang=ar` أو `?lang=en`)، ثم اللغة المحفوظة محليًا، ثم الإنجليزية. تبديل اللغة يحافظ على بقية معاملات الرابط وجزء `#`، ويحدّث اتجاه المستند.

المصدر المركزي لبيانات الصفحات هو `src/lib/seo.ts`. يُولّد البناء ملفات HTML ببيانات عنوان ووصف ومشاركة وcanonical لكل صفحة معروفة، وملفي `sitemap.xml` و`robots.txt`، بما يشمل صفحات التفاصيل. صورة المشاركة الافتراضية ملف موجود داخل `public/hero/`.

اضبط `VITE_SITE_URL` على عنوان النشر الكامل، بما فيه مسار المستودع عند استخدامه. مسار GitHub Actions يستخرجه من إعداد GitHub Pages. محليًا، الافتراضي هو `https://elmekawy-bim.com/` مع مسار البناء.

ملفات HTML تحمل بيانات المشاركة الإنجليزية قبل تشغيل JavaScript؛ تُحدّث البيانات للعربية في المتصفح عند اختيارها. معاملات اللغة وحدها لا تتيح تخصيص استجابة HTML الأولية لكل لغة على GitHub Pages. المحتوى الأساسي ما زال يُعرض عبر React؛ هذا التغيير ليس عرضًا كاملًا من الخادم.
